Welcome to DAEtesting2

A simple project showcasing a dark mode toggle built with plain HTML, CSS, and JavaScript.

No Dependencies

This project is built entirely with vanilla HTML, CSS, and JavaScript. No frameworks or build tools required.

Persistent Preference

Your dark mode preference is saved to localStorage and automatically restored on your next visit.

Smooth Transitions

All theme changes are animated with CSS transitions for a polished user experience.

About This Page

This page demonstrates a lightweight dark mode implementation. Click the toggle button in the header to switch between light and dark themes.

The toggle updates the page styling instantly and stores your choice in the browser so it persists across reloads. No server or external resources are needed.
